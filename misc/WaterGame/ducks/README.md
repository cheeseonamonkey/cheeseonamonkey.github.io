# Duck assets

WaterGame bundles transparent SVG duck artwork locally so the game does not depend on an image API.

- `fluent-*.svg` — Microsoft Fluent Emoji, from `microsoft/fluentui-emoji` (MIT).
- `twemoji.svg` — Twemoji duck artwork, from `jdecked/twemoji` (CC-BY 4.0 artwork).
- `openmoji-*.svg` — OpenMoji duck artwork, from `hfg-gmuend/openmoji` (CC BY-SA 4.0).

The files remain in their original transparent SVG form.
